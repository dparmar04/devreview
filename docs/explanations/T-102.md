# T-102 - Find bug-fix commits

## What it is
A way to search through a git repo's history and find commits that fixed bugs. We identify them by their commit message — if it says "fix", "bug", or "hotfix", we flag it. Think of it like searching your email inbox for messages with "urgent" in the subject line — it is a keyword filter, not a guarantee.

## What I built here
A function `find_fix_commits(repo_path)` that returns a list of commit SHAs (the unique IDs git gives every commit) that look like bug fixes. DevReview needs this because to grade an AI code reviewer, you need examples of code that had real bugs. If a later commit *fixed* a bug, then the code before that fix *contained* a bug — that is the ground truth we are building toward.

## How it works
1. Call `git log --no-merges --format=%H<SEP>%s` — this lists every non-merge commit with its SHA and subject line, separated by `<SEP>`.
2. For each commit, check the subject against the regex `(?i)\b(fix(es|ed)?|bug|hotfix)\b`.
   - `(?i)` = case-insensitive (matches "FIX", "Fix", "fix")
   - `\b` = word boundary — "prefix" does NOT match because "fix" is in the middle of a word, not on its own.
3. Skip any commit whose subject starts with "Revert" — those undo a fix, they are not fixes themselves.
4. Return the matching SHAs in a list, newest first.

## How to see it working
```python
python -c "from devreview.dataset.git_history import find_fix_commits; print(find_fix_commits('.'))"
```
Run this in the devreview repo itself. It prints a list of SHAs — which may be empty if no commits in this repo use fix/bug/hotfix keywords. The tests use throwaway repos with known commits to verify it works.

## What could go wrong
- **False positives:** A commit saying "fix typo in README" is found, but it is not a *bug* fix. The keyword heuristic is only a guess — it catches things that are not real bugs.
- **False negatives:** A commit saying "resolve crash on login" would NOT be found because "resolve" is not in the keyword list. Real bugs can be missed.
- **Revert edge case:** A commit like "Revert a bad revert of a fix" would be excluded (starts with "Revert"), even though it might re-apply a real fix.
- **Git not installed:** If `git` is not on PATH, `subprocess` raises `FileNotFoundError`.
